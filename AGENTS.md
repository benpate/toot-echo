# toot-echo — Notes for AI Agents

Toot-echo mounts a [toot](https://github.com/benpate/toot) Mastodon API on an Echo router: [register.go](register.go) is one registration line per endpoint, and [register-private.go](register-private.go) wraps every handler in the same authorize → check scope → bind → JSON pipeline. See [README.md](README.md) and [doc.go](doc.go) for orientation.

- **Each line of Register names the same endpoint four times — Echo method, `route.X`, `api.X`, `scope.X` — and nothing but a test makes them agree.** A mismatch still compiles: it registers the wrong path, or guards a route with another endpoint's scope. Worse, Echo silently overwrites a duplicate method+path registration, so a wrong route constant makes one endpoint vanish while another answers in its place. [register_consistency_test.go](register_consistency_test.go) parses register.go and fails when the four names disagree, when the Echo method contradicts the name's verb prefix, or when a method+path appears twice; run `go test .` after any change to register.go.
- **Always forward the variadic middleware with `middleware...` at every level.** `Register` → `single_result`/`paged_result` → `any_result` each accept `...echo.MiddlewareFunc`; dropping the spread (or the argument) at any hop compiles cleanly and silently discards the caller's middleware. `any_result` prepends `WithHost` so it runs before the caller's middleware — keep that ordering.
- **This package enforces OAuth SCOPE only, never object-level authorization.** `verifyScope` answers "does this token carry the scope this endpoint requires" (a parent scope like `read` satisfies `read:accounts`; `scope.Public` skips `Authorize` entirely and hands the handler a zero AuthToken; `scope.Private` requires a valid token but no particular scope). Whether that token may touch a particular account, status, or list is the application handler's job — Emissary's `handler/mastodon` package (which has its own AGENTS.md) is the downstream consumer that does this.
- **The CORS header is set at the TOP of the handler, before authorization can fail.** Setting `Access-Control-Allow-Origin` after the handler runs would strip it from error responses, leaving browser clients unable to read error bodies. The wildcard origin is safe here because authorization rides on Bearer tokens, not cookies.
- **Pagination headers go through `PageInfo.SetHeader(ctx.Response().Header(), path)`, never `PageInfo.SetHeaders`.** `SetHeaders` reads `http.Request.Response`, which is always nil on the server side, so calling it here silently emits no `Link` header at all.
- **`WithHost` trusts `X-Forwarded-Host` unconditionally — deliberate, not a bug to fix here.** A Mastodon API must report the instance's public hostname, so the middleware rewrites the request's Host header from that proxy header. The deployment must run behind a proxy that overwrites it; without one, a client can pick the hostname that appears in its own responses. This is documented in [doc.go](doc.go); don't add validation logic, and don't remove the warning.
- **Error rendering belongs to the host application.** Handlers return derp errors and this package wraps and re-raises them; Echo's default error handler renders anything unfamiliar as a 500, so the host must install a derp-aware `HTTPErrorHandler` to get real status codes.
- **The `single_result`/`paged_result`/`any_result` underscore names are intentional.** They mirror the toot library's own underscore naming style; revive's var-naming complaints about them are known and accepted, so don't rename them.
- **A nil handler field is skipped, not registered.** An API that implements ten endpoints serves ten routes and 404s the rest; "missing" routes usually mean the application never assigned that handler, not a bug here.
